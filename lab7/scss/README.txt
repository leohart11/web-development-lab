Haranga Lab 7 SCSS files

1. Copy this scss folder's contents into your existing lab7/scss folder.
2. Keep the existing lab7/css folder and image/video folders.
3. In lab7/index.html, link the compiled stylesheet:
   <link rel="stylesheet" href="css/style.css">
4. From the lab7 folder, run:
   npm.cmd install -D sass
   npm.cmd run sass

The Sass source is split into tokens, mixins, functions, base, layout, and components.
The original CSS selectors and visual values are retained. Existing carousel/flip styles are kept.
